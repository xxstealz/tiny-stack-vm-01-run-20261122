# Tiny Stack VM

A small, exact interpreter of make.fun's tiny stack ISA: 32-bit wrapping
arithmetic, a 256-value stack, 64-deep call stack, 256 words of memory,
input/output, and all ten traps with their own exit codes, plus the step
and output limits. `main.ts` (Node 22, stdlib only) answers every instance
in `/input/<id>/`, writing `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.
